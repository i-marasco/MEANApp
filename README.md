# MeanApp

Full-stack web application developed with **Angular, Node.js, Express and MySQL**, using **Docker** for containerization.

## Technologies

* Angular
* Node.js
* Express
* MySQL
* Docker

## Run the application

Create a `.env` file in the root directory with the required environment variables.

Then run:

```bash
docker compose up --build -d
```

## Access

* Frontend: http://localhost:4200
* Backend: http://localhost:3000
* MySQL: `localhost:3306`
